Счётчик пересчётов растёт только при реальном изменении итога — это и есть мемоизация computed(). Обычный геттер в Angular 16 вызывался бы на каждом проходе change detection.

@for (entry of log(); track $index) {
{{ entry }}
} @empty {
Эффект ещё не срабатывал.
}

Внутри effect() запись в сигнал тоже нужно оборачивать в untracked(), иначе эффект зациклится сам на себе.

Координаты {{ coords().x }} : {{ coords().y }}
Срабатываний effect {{ coordsNotifications() }}

Нажмите «те же координаты» несколько раз: счётчик срабатываний не изменится.
